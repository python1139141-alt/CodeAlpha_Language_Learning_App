# 🌍 Language Learning App — CodeAlpha Internship Task

A feature-rich, interactive Mobile & Web application built with **Flutter** for learning new languages through flashcards, native audio pronunciations, and quizzes. Built as part of the **CodeAlpha App Development Internship**.

---

## ✨ Features
- 🚀 **Onboarding Setup**: Personalized setup for User Name, Native Language, Target Language, and Expertise Level (No external login required).
- 🗂️ **Categorized Vocabulary**: Learn words across multiple real-world categories (Greetings, Travel, Food, Daily Phrases).
- 🔊 **Text-to-Speech (TTS)**: Built-in native pronunciation with Normal and Slow (0.5x) speed options using `flutter_tts`.
- 🎴 **Interactive Flashcards**: Animated flip cards showing target words, translations, and example sentences.
- 🧠 **Practice Quizzes**: Multiple-choice testing engine with score tracking and XP rewards.
- 🔖 **Saved Words & Bookmarks**: Save difficult vocabulary locally for revision.
- 📊 **Local Progress Tracking**: Persistence layer powered by `shared_preferences` for tracking streaks and XP.

---

## 🛠️ Tech Stack & Dependencies
- **Framework:** Flutter (Dart)
- **Local Storage:** `shared_preferences`
- **Audio Engine:** `flutter_tts`
- **UI & Fonts:** Material 3, `google_fonts`, `percent_indicator`
